KEMI 远程办公技术支持

Official support for KEMI Remote Office on macOS

开始使用 / Getting started

  1. 在自己的 Mac 上安装并打开 KEMI 远程办公。
  2. 需要被控功能时，由设备所有者在 macOS 系统设置中授予屏幕录制或辅助功能权限。
  3. 使用远端设备 ID 发起连接；远端用户应确认访问并管理访问密码。
  4. 经远端授权后，可查看屏幕、进行鼠标键盘操作，或按需传输文件。

连接与本机界面不要求创建 KEMI 账号。未获得设备所有者许可时，请勿尝试远程控制。

常见排查 / Troubleshooting

  • 连接失败：确认两端在线、设备 ID 正确，并检查网络连接。
  • 能连接但看不到屏幕：检查被控 Mac 的屏幕录制权限。
  • 能看到屏幕但无法操作：检查被控 Mac 的辅助功能权限与远端授权状态。
  • 无法保存文件：为目标目录授予 macOS 所需的文件访问权限。
